# 👨‍💻 fluxo de trabalho Git

este documento descreve um fluxo básico de versionamento com Git, focado na organização do desenvolvimento.

---

## workflow

1. inicializar o repositório
	- `git init`

2. configurar o ambiente 
	- `git config`

3. criar ou modificar arquivos

4. verificar o estado do repositório
	- `git status`

5. adicionar alterações ao stage
	- `git add <arquivo>`

6. revisar alterações
	- `git diff`
	- `git diff --staged`

7. registrar as alterações
	- `git commit -m "descrição do commit"`

8. repetir o ciclo 
	- voltar ao passo 3
